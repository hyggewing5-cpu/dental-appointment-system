# ระบบนัดคิวทันตกรรมออนไลน์

เว็บหน้าผู้ป่วย + หลังบ้าน Admin (HTML/CSS/JS ล้วน ใช้ได้ทุกอุปกรณ์) เก็บข้อมูลใน Google Sheet ผ่าน Google Apps Script

## โครงสร้างไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าผู้ป่วย: จองนัด / ตรวจสอบ-เลื่อนนัด / จองนัดครั้งถัดไป / ใบนัด (บันทึกภาพ, พิมพ์) |
| `admin.html` | หลังบ้าน: ตารางนัดรายวัน, **สรุปรายวัน + เดชบอร์ด/รายงานรายเดือน (พิมพ์ / CSV)**, เปลี่ยนสถานะ 5 สี, เพิ่มนัดเช้า/บ่าย/Walk-in, ค้นหาผู้ป่วย, ปิดวัน, ตั้งค่า, ประวัติการแก้ไข |
| `engine.js` | กฎทั้งหมดของระบบ (ไฟล์เดียวกันใช้ในเบราว์เซอร์โหมดสาธิต และใน Apps Script) |
| `api.js`, `style.css`, `config.js` | ตัวเชื่อม API / ธีม / ค่าตั้งต้นของหน้าเว็บ |
| `apps-script/Code.gs`, `Engine.gs`, `appsscript.json` | ฝั่ง Server (Google Sheet) |
| `test/` | ชุดทดสอบกฎ (`node test/engine.test.js`) และทดสอบหน้าจอ (`test/e2e.js`) |

ลองดูทันทีได้โดยเปิด `index.html` / `admin.html` (โหมดสาธิต เก็บในเบราว์เซอร์ รหัส Admin: `admin` / `admin1234`)

## ติดตั้งใช้งานจริง
1. สร้าง Google Sheet ใหม่ (ห้ามแชร์สาธารณะ) → เมนู **ส่วนขยาย > Apps Script**
2. สร้างไฟล์ `Code.gs`, `Engine.gs` ตามโฟลเดอร์ `apps-script/` และเปิดแสดง `appsscript.json` ใน Project Settings แล้ววางเนื้อหา
3. กลับมาที่ Sheet รีเฟรช → เมนู **ระบบนัดทำฟัน**: (1) ติดตั้งระบบ → (2) เพิ่ม Admin (ตั้งรหัสผ่าน) → (3) ตั้งเวลาสำรอง/ลบข้อมูลเกิน 1 ปี
4. **Deploy > New deployment > Web app** (Execute as: Me, Access: Anyone) แล้วคัดลอก URL `/exec`
5. ใส่ URL ใน `config.js` (`API_URL`) แก้ชื่อโรงพยาบาล/เบอร์ติดต่อ แล้วอัปโหลดทั้งโฟลเดอร์ขึ้น Netlify (หรือ GitHub Pages)

หลังแก้โค้ด Apps Script ต้อง Deploy เวอร์ชันใหม่ทุกครั้ง

## สิ่งที่ตัดสินใจเพิ่มจากเอกสาร (โปรดตรวจ)
- **ยืนยันตัวตนตอนเลื่อนนัด:** ใช้เลขที่นัด + เบอร์โทร + รหัส 4 หลักบนใบนัด (ไม่ใช้เบอร์อย่างเดียวตามข้อ 15) และจำกัดการลองผิด
- **“ผู้ป่วยคนเดียวกัน”** ตัดสินด้วยเบอร์ + ชื่อ + นามสกุล (ครอบครัวใช้เบอร์เดียวกันจองแยกได้) ปรับได้ที่ `patientKeyMode`
- **เลขนัด** `Dวันเดือนปี-ลำดับ` อิงวันที่ทำรายการจอง (เช่น D101126-001)
- **เลื่อน/ยกเลิกนัดเอง** ได้ก่อนวันนัดอย่างน้อย 1 วัน (ยกเลิกเอง = เปลี่ยนสถานะเป็น “ยกเลิก” ไม่ลบข้อมูล และคืนคิวให้ผู้อื่นจอง) (ปรับที่ `rescheduleMinDays`); นัดช่วงบ่าย/เคสทันตแพทย์กำหนดเวลา ต้องให้ Admin เลื่อน
- **Walk-in** เก็บแยก ไม่นับเป็นนัดที่ยังใช้งานอยู่ และไม่กระทบคิวออนไลน์
- ปิดวัน: แสดงรายชื่อผู้ได้รับผลกระทบ + ขอให้ยืนยัน และ **ไม่ยกเลิกนัดอัตโนมัติ**
- การจองพร้อมกันป้องกันด้วย Script Lock + กันส่งซ้ำ (requestId)
- ยังไม่มี SMS/LINE แจ้งเตือน (ไม่อยู่ในสเปก) เพิ่มภายหลังได้

## ความปลอดภัย
รหัสผ่าน Admin เก็บแบบ hash + salt ใน Sheet ฝั่ง Server, Token ตรวจที่ Server, API หน้าผู้ป่วยส่งเฉพาะ “เวลาว่าง” ไม่ส่งข้อมูลผู้ป่วยคนอื่น, ไม่ลบนัดเดิมเมื่อยกเลิก/เลื่อน (เก็บ Audit Log พร้อมชื่อ Admin และเวลา)
